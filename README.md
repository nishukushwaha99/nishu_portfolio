## 🌟 Key Features

- **Cyber Obsidian Glassmorphism**: Tailored dark theme with smooth gradients, neon accents, and backdrop blur.
- **Dynamic Theme Palette**: Instant live switching between 4 accent themes (Cyber Cyan, Royal Violet, Neon Emerald, Sun Amber).
- **Interactive Audio Synthesizer**: Built with native Web Audio API oscillators for click, theme-switch, and feedback audio cues.
- **Interactive Devbox CLI Terminal**: Built-in interactive console for exploring Nishu's education, skills, projects, and contact bio-data via commands (`about`, `skills`, `education`, `projects`, `biodata`, `contact`).
- **Hero Image Slider & 3D Tilt**: Smooth multi-photo slider with swipe gesture support, keyboard navigation, and interactive 3D card tilt.
- **Project Showcase & Filter**: Filterable portfolio items with details modal viewer.
- **Academic Credentials & Resume Modal**: Instant viewing of academic milestones, certifications, and complete bio-data.
- **100% Zero-Dependency Build**: Written in pure HTML5, modern CSS3, and Vanilla JavaScript with CDN assets. No complex bundlers or node runtime required.

## 🌐 Deploying to GitHub Pages

### Option A: GitHub Actions (Recommended)
This repository includes `.github/workflows/deploy.yml`. When enabled:
1. Go to your repository on GitHub: **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Every time changes are pushed to `main`, GitHub Pages deploys automatically.

### Option B: Deploy from Branch
1. Go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
